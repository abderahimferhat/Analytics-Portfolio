# Retail Sales Performance Dashboard

Interactive Power BI dashboard analyzing retail sales performance across regions, product categories, and sales representatives.

## Tools & Techniques
- **Power BI:** Data modeling, DAX measures, interactive visuals, AI-generated narrative insights
- **Visuals used:** clustered column charts, pie chart, bar chart, line chart, gauge, map (regional), detail table

## What's in the Dashboard
**Page 1 — Sales Performance Overview**
- Profit by region and product category (clustered column chart)
- Revenue tracked against target (gauge)
- Sales rep performance breakdown (table)
- Units sold by product category, broken down by year/quarter/month/day (time-hierarchy drill-down)
- Revenue share by region (pie chart)
- Profit by region (bar chart)
- Units sold trend by sales rep over time (line chart)
- Regional sales distribution (map)

**Page 2 — AI-Generated Insights**
- Automated narrative summary highlighting key trends and outliers in the data

## Key Skills Demonstrated
- Building a multi-visual, cross-filterable dashboard from a single retail sales dataset
- Using date hierarchies for time-based drill-down analysis
- Combining geographic, categorical, and time-series views to tell a complete performance story
- Leveraging Power BI's AI narrative feature to auto-generate data insights
